HOW TO TRUST IT

  1. Every fact has a source. The agent must quote the exact sentence; the quote is checked in code before it counts.
  2. An independent check. A separate judge decides if each quote really supports the fact. Anything that fails is thrown out, shown crossed out.
  3. A skeptic. Another agent reviews the work, objects to thin evidence, and sends the analyst back.
  4. Disagreements are shown, not hidden: two sources with different numbers both appear, flagged in red.
